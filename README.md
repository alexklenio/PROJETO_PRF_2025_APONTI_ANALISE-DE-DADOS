## Detalhes da formação
A Formação Acelerada em Programação (FAP) da APONTI, na trilha de Análise de Dados, é uma capacitação intensiva voltada à preparação de novos profissionais para o mercado de tecnologia. Na edição de 2026, o programa passou a oferecer três trilhas — Análise de Dados, DevOps e Teste de Software — com 215 horas de formação, distribuídas entre atividades presenciais e virtuais.

Trilha de Análise de Dados

A proposta é desenvolver uma formação prática para que o participante consiga trabalhar com dados, identificar padrões, gerar informações relevantes e apoiar decisões de negócio. Mais do que aprender ferramentas isoladamente, a formação busca desenvolver o raciocínio analítico e a capacidade de solucionar problemas utilizando tecnologia.

De forma geral, a formação envolve competências como:

    Lógica e programação, criando uma base para trabalhar com dados de maneira estruturada;
    Python, como linguagem para tratamento e análise de dados;
    Manipulação e preparação de dados, incluindo organização, limpeza e transformação de bases;
    Análise exploratória, buscando padrões, tendências e informações relevantes;
    Estatística aplicada, necessária para interpretar corretamente os dados;
    Visualização de dados, transformando informações em gráficos e representações que facilitem a compreensão;
    Construção e interpretação de indicadores;
    Resolução de problemas reais, aproximando o aprendizado das demandas encontradas nas empresas.

Um diferencial importante da FAP é justamente a combinação entre formação técnica e experiência prática. O programa prevê a possibilidade de uma Residência Técnica de três meses, na qual os participantes selecionados podem aplicar os conhecimentos adquiridos em projetos reais de empresas parceiras. A APONTI também utiliza projetos integradores para aproximar os estudantes de problemas concretos do mercado.

Em resumo, a trilha de Análise de Dados da FAP pode ser entendida como uma formação acelerada para quem deseja sair de uma base inicial e desenvolver competências para atuar com programação, tratamento, análise e interpretação de dados, com uma abordagem voltada à empregabilidade e às necessidades reais do setor de tecnologia.
